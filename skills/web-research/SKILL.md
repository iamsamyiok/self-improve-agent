# 联网调研

## 何时使用

- 用户要求查询天气、新闻、价格、技术资料等实时信息
- 需要多来源交叉验证某个事实

## 步骤

1. `search(query=核心关键词)` 拿到结果列表，从标题与摘要挑最相关的 1-3 条
2. `fetch(url=选中链接)` 读正文（已自动去噪，标题置顶）
3. 长正文用 `fetch(url, offset=N)` 分段读完，不要只看开头
4. 关键结论（温度/价格/版本号等）用第二个来源交叉验证，或用 `bash` curl 结构化 API（如 wttr.in 查天气）
5. 汇总时注明信息来源与时间

## 注意

- fetch 返回已剥离导航菜单，直接找数据区
- JSON API 用 `fetch(url, parseJson=true)` 拿结构化输出
- 搜不到时换英文关键词或同义词重试一次
