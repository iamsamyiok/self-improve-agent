# 长文分段写入

## 何时使用

- 目标文件内容预计超过 1500 字符
- 曾收到「参数在 API 传输中丢失/截断」提示
- 需要在已有内容的文件后追加内容

## 步骤

1. 规划分段：把完整内容按语义边界（章节/函数/段落）切成 ≤1500 字符的段，段与段不重叠、不跳行
2. 首段：`write(path=目标路径, content=第一段)`——文件不存在时直接创建
3. 后续每段：`write(path=同一路径, content=下一段, append=true)`
4. 写完用 `read(path, tail=10)` 确认末尾衔接正确
5. 若某段返回「幂等保护」，说明该段已写入成功，直接继续下一段

## 禁止事项

- 绝不用普通 write 续写（会整体覆盖之前的段落）
- 收到截断提示后禁止第三次原样重发大参数
