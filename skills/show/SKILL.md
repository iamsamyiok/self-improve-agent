# Show：48 小时临时静态发布

Show 是面向 Agent 的临时静态托管服务（基于 Cloudflare 免费额度）。把目录打包成 tar.gz 上传，即刻获得公网 URL，48 小时后自动过期。无需安装 CLI——只需 bash、tar、curl 与 node（解析响应 JSON）。

## 何时使用

- 用户想临时把网页/页面/演示分享到公网（「给我个链接」「发到网上让人看看」）
- 用户想把一批文件（文档、图片、压缩包、数据集）封装成下载网页分享
- 构建完前端项目后用户想要一个可分享的线上地址

与平台内建能力的区别：平台 `deploy-website` 只能本环境预览；Show 部署的是**公网可访问**的临时站点（48 小时有效）。正式长期发布请用平台发布通道，Show 定位是「短时间、随手分享」。

## 硬约束

| 约束 | 值 |
|------|-----|
| 单次上传 | ≤ 10 MB（压缩与解压后都算） |
| 单次文件数 | ≤ 100 个 |
| 存活时间 | 48 小时（自动删除，无法续期） |
| 文件类型 | 仅静态文件：HTML/CSS/JS/JSON/图片/字体/SVG/XML 等 |

**发布前必做安全检查**：待发布目录绝不能包含敏感文件——`.env`、密钥/凭据文件、`*token*`、`*secret*`、`.git/`、数据库文件、用户数据。发现敏感文件先剔除或向用户确认。这是公网可访问的内容，按公开处理。

**大文件先规避再动手**：目标产物中任一文件超过 8 MB（如 APK/安装包/视频/数据集）就不要下载并打包进站点——10 MB 上限必然发布失败，白白浪费下载与重试。正确做法是规划期就改道：用官方直链（如 pkgs.tailscale.com）、GitHub Releases 或用户自己的服务器承载大文件，show 页面只放指向该直链的下载按钮。

## 匿名上传，无需任何凭据

公开实例 `show.127.dev` 接受匿名上传（按 IP 限流）。**不要向用户索要 token，不要检查 SHOW_TOKEN 环境变量，不要因为没配置就停下**——直接部署。只有用户明确给了自托管地址（SHOW_API_URL）时才可能用到 token。

## 模式 A：发布静态站点

1. 定位构建产物目录：依次找 `./dist`（Vite/Webpack）、`./build`（CRA）、`./out`（Next 静态导出）、`./public`（纯静态站）；都没有则先帮用户构建（`npm run build`）
2. 打包上传（推荐用本技能自带的部署脚本）：

```bash
# 脚本位于技能目录，自动完成打包、上传、解析结果；--spa 用于 React Router/Vue Router 等前端路由项目
bash "<技能目录>/deploy.sh" <产物目录> <项目名> [--spa]
```

也可手动执行等效命令：

```bash
# 打包产物目录并上传到 Show，返回 JSON 含 url 与过期时间
tar czf /tmp/show-upload.tar.gz -C <产物目录> . && \
curl -s --max-time 120 -X POST "https://show.127.dev/upload" \
  -F "file=@/tmp/show-upload.tar.gz" \
  -F "name=<项目名>" && \
rm -f /tmp/show-upload.tar.gz
```

SPA 项目在手动命令中追加 `-F "mode=spa"`（脚本则加 `--spa` 参数）。

3. 响应为 JSON：`{"deploymentId":"a3f9x2-xxx","url":"https://a3f9x2-xxx.127.dev","expiresAt":"...","mode":"static"}`

## 模式 B：把文件封装成下载网页

用户想分享的是**文件资源**（文档/图片/数据包）时，生成一个下载列表页再随文件一起上传：

1. 建临时目录（如 `/tmp/show-pkg`），把要分享的文件拷入
2. 在目录里生成 `index.html`：简洁的文件列表页，每行一个文件名 + `<a href="<文件名>" download>` 下载链接 + 文件大小，顶部标注「该分享 48 小时后过期」；中文标题，样式内联保持单文件
3. 用与模式 A 相同的脚本/命令上传该目录，把返回的 URL 交给用户——访客打开即是下载页

## 向用户报告结果

必须包含三项：

- **访问 URL**（响应里的 `url` 字段）
- **精确过期时间**：解析 `expiresAt` 并格式化为本地时间的「年-月-日 时:分」（如「2026-03-21 15:30 过期」），禁止只说「48 小时后」
- **部署 ID**（`deploymentId`），便于后续查询

查询某个部署状态（可选）：

```bash
# 查询部署详情与剩余时间
curl -s --max-time 30 "https://show.127.dev/_admin/deployments/<部署ID>"
```

## 失败处理

- **429/限流**：公开实例按 IP 限流，提示用户稍后再试；用户高频使用可引导其自托管（见下方）
- **超 10 MB / 超 100 文件**：剔除非必要文件、压缩大文件、或拆分多次部署（每次一个下载页）
- **网络不可达/超时**：如实报告，建议用户稍后重试；不要伪造 URL
- 上传成功但页面 404：确认产物目录根有 `index.html`（模式 B 必须生成）

## 自托管（可选）

用户有 Cloudflare 账号可零成本自托管 Show（服务端开源）：设置 `SHOW_API_URL` 指向自托管地址即可，脚本与手动命令都自动遵循该变量。参考 https://github.com/polunzh/show 的 Self-Hosting 文档。
