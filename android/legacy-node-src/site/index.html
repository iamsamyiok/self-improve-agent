wsl agent Android 版

工作空间生命体的安卓形态：nodejs-mobile（Node 18.20.4）在 App 内运行完整服务端， WebView 直连 127.0.0.1 纯聊天流界面。零 npm 依赖的架构原样迁移，所有状态存于 App 私有目录。

技术要点

  • 运行时：nodejs-mobile v18.20.4（libnode.so 经 node::Start JNI 桥启动）
  • 生命周期：Foreground Service（dataSync）常驻通知，Doze 下任务不中断
  • 安全：服务仅绑 127.0.0.1；WebView 放行环回明文，外链强制浏览器；API Key 存私有目录
  • bash 适配：toybox 能力探测 + 命令重写（grep -P→-E 等）+ not found 自纠提示
  • 导出：交付文件经 FileProvider 拉起系统分享
